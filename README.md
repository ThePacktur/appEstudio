## 🧠 Funcionalidades principales

### 1) Técnicas de estudio
Accede a una lista de técnicas para distintos estilos de aprendizaje:

- Pomodoro
- Feynman
- Mapa Mental
- Repetición Espaciada
- SQ3R

Y en **Premium**:

- Active Recall
- Interleaving
- Autoevaluación
- Analogías
- Diagramas

### 2) Rutinas inteligentes
Crea rutinas con:

- Nombre de rutina
- Técnica seleccionada
- Horario en formato `HH:MM`

La app valida los datos para ayudarte a mantener tus rutinas limpias y consistentes.

### 3) Temporizador de enfoque
Inicia una técnica y concéntrate hasta completar tu sesión. Puedes:

- Iniciar / Pausar
- Reiniciar
- Volver al listado de técnicas

### 4) Suscripción Premium
Desbloquea todo el catálogo de técnicas avanzadas por **$10**.

Ideal para estudiantes que quieren acelerar resultados con estrategias de mayor impacto.

## 🚀 Instalación y ejecución

## Requisitos

- Python 3.10+
- `kivy`

## Pasos

```bash
# 1) Clona el repositorio
git clone <URL_DEL_REPO>
cd appEstudio

# 2) (Opcional pero recomendado) crea un entorno virtual
python -m venv .venv
source .venv/bin/activate   # En Windows: .venv\Scripts\activate

# 3) Instala dependencias
pip install kivy

# 4) Ejecuta la app
python StudyApp/main.py
```
